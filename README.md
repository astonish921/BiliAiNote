## 产品定位
BiliAiNote是个开源的标准的浏览器扩展插件，通过AI智能识别技术，自动获取或语音识别B站视频字幕，自动获取或AI总结视频出视频章节，对识别内部进行AI总结，方便用户快速理解视频讲解核心内容。并支持在细看视频的过程中对关键画面进行截图、备注，并对字幕/截图/备注提供检索功能，方便后续查阅知识。
## 解决痛点
1. 初筛视频时间成本高：30min+的视频，从头看到尾看一遍太耗时间，无法快速了解视频整体思路从而判断是否需要进一步细看。
2. 部分视频没有字幕：部分视频从 B 站接口无法直接获取视频字幕和章节信息，没有输入内容导致无法进行分析总结。
3. 笔记与视频脱节：截图、时间点、文字内容散落各处，复习时找不到「这段话在视频第几分钟」。
## 产品特点
1. 自动抓取/识别字幕：自动获取 B 站视频字幕（多语言切换、含 AI 字幕）；无字幕视频可配合本地客户端BilibiliDownloader语音转写自动生成字幕。
2. AI 智能总结：接入任意 OpenAI 兼容大模型，内置「文档总结」「学习指导」提示词，支持自定义，流式输出，结果按视频缓存无需重复整理。
3. AI 智能章节：视频无章节时，基于字幕一键生成章节列表，点击章节直达播放位置。
4. 笔记一体化：字幕行可添加备注、视频帧截图，全部按视频持久化，刷新自动恢复。
5. 快速检索定位：字幕关键词即时搜索高亮、备注搜索、「只看截图/只看备注」过滤，点击命中行跳转视频播放位置。
6. 多格式导出：SRT 字幕、Markdown 笔记（含截图时自动打包 ZIP），章节/时间戳可勾选控制。
7. 一键下载视频：可配合本地客户端BilibiliDownloader下载B站视频。
